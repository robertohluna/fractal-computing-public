Architecture

How Fractal makes this possible

The language model does only the first and last steps. Fractal does the heavy lifting in between.

  1. The systems of record are left in place.Data is copied from them in one direction only. Nothing is ever written back.
  2. Fractal maintains a live digital twin.The twin is updated continuously and runs on commodity hardware the organization controls.
  3. The twin is divided across many small instances.Each instance holds one shard of the data and a complete software stack, so processing happens where the data is.
  4. The model writes a small program, and every instance runs it at once.Results are deterministic: the same question returns the same answer, and every figure can be traced to its source.
  5. Only results return to the model.Fractal aggregates the results and the model presents them in plain language. Source data is never sent to the model.
Safety

AI has no write access to production. Nothing it does can corrupt the systems of record.

Cost

The model handles only the request and the result, so token costs depend on the question, not on the volume of data.

Sovereignty

Source data stays on hardware the organization controls and is never passed to the model.

  2. Stage 2
